# Fonts

The renderer uses **Cabinet Grotesk** for everything. Files in this directory:

- `CabinetGrotesk-Regular.otf` (400)
- `CabinetGrotesk-Medium.otf` (500)
- `CabinetGrotesk-Bold.otf` (700)

Free for commercial use under the Fontshare licence — get the files from https://www.fontshare.com/fonts/cabinet-grotesk if you need to replace them.

Satori only accepts `.ttf` or `.otf` (not `.woff2`); do not swap formats without checking `lib/render/fonts.ts`.
